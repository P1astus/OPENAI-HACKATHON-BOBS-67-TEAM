# MAIN 08

Team MAIN 08 at the MAIN Summit & AI Hackathon 2026 (Maastricht, 20–21 Nov), reltix track "Plug a Partner into centrix". We're building repair matching: when something breaks in an apartment, find the best company to fix it, book it with the tenant, bill the owner and rate the company afterwards.
